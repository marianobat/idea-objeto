# De la idea al objeto

Sitio de recursos del taller (Ciclos de Creatividad, Universidad Siglo 21).

## Publicar en GitHub Pages

1. Subí todo el contenido de esta carpeta a la raíz del repositorio, tal como está (incluido el archivo oculto `.nojekyll`).
2. En el repositorio: Settings › Pages › Build and deployment › Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`.
3. El sitio queda en `https://<usuario>.github.io/<repositorio>/`.

## Archivos

| Archivo | Qué es |
|---|---|
| `index.html` | Página principal |
| `img/siglo21.png` | Logo |
| `motor-cantidades.html`, `motor-agentes.html` | Motores (funcionan también sin conexión) |
| `prompt-cantidades.html`, `prompt-agentes.html` | Prompts para ChatGPT, con botón para copiar y descarga del motor |
| `faro-una-moda-en-el-curso.html` | Ejemplo hecho con el micromundo de agentes |

## Publicar un objeto del taller

1. Subí el `.html` del equipo a la raíz del repositorio (por ejemplo `equipo-3-erosion.html`).
2. En `index.html`, en la sección "Objetos desarrollados en el taller", copiá el bloque `<a class="card" …>` del ejemplo, cambiá `href`, el equipo y el título, y borrá uno de los bloques "Próximamente".
